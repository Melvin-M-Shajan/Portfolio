## The retrieval problem

Flat vector retrieval is excellent at finding passages that resemble a question. Multi-hop questions are different: the answer often depends on following explicit relationships across several entities.

## Draft argument

- Define the difference between semantic similarity and relational traversal.
- Compare a flat vector baseline with graph-expanded retrieval.
- Show where hybrid retrieval improves evidence coverage.
- Explain the latency and graph-quality trade-offs.

## Evaluation plan

The finished post will compare both approaches using the same multi-hop question set, retrieval budget, and answer-evaluation rubric. No performance claims will be published until the benchmark is reproducible.
